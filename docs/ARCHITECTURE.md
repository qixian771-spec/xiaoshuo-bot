# `xiaoshuo-bot` 生产架构与 `AI-TIC-CHECK` 规范文档

## 1. 设计目标

传统大模型长篇小说生成普遍存在三大顽疾：
1. **器物与时空失忆**：前一章留在修表台上的怀表，下一章凭空出现在角色口袋；埋下的伏笔到完结仍未回收。
2. **视角越界（Head-Hopping）**：名为第三人称限知视角，实则频繁切入配角内心（“他心想”）或跳出全知预告（“殊不知”）。
3. **AI 惯性套话污染**：高频出现“不禁一愣”、“心中一紧”、“眸光微闪”、“不是A，而是B”、“这一刻，命运的齿轮……”等机械表达。

`xiaoshuo-bot` 将提示词工程升级为**受控状态机 + 确定性编译器 + 静态质量门禁 + 自动重写闭环**。

## 2. 执行管线数据流

```text
[YAML 资产库: characters / assets / foreshadows / style_profiles / outline]
        │
        ▼
[WorldStateManager] ──(读取当前章器物实时位置 & 到期伏笔)──► [PromptCompiler]
                                                                  │
                                                    编译五段式限知生产提示词
                                                                  │
                                                                  ▼
                                                           [LLMProvider]
                                                                  │
                                                              生成候选正文
                                                                  │
                                                                  ▼
                                                           [AITicChecker]
                                                          ╱              ╲
                                              命中任一禁令(CRITICAL)      0 违规通过
                                                        ╱                  ╲
                                                       ▼                    ▼
                                         记录 ProductionIncident    落盘纯正文 chapter_XX.txt
                                         生成靶向 Rewrite Prompt     推进器物状态 & 核销到期伏笔
                                         回送 LLMProvider 重写      保存快照 chapter_XX_after.json
```

## 3. 门禁规则矩阵 (`checker.py`)

| 规则组 | 规则编码范围 | 检测目标 | 处置级别 |
| :--- | :--- | :--- | :--- |
| 输出格式门禁 | `FMT_000`–`FMT_007` | 首字符非正文汉字、Markdown 标题、章节号、分割线、代码围栏、作者手记 | `CRITICAL`（强制打回重写） |
| 总结腔/升华词 | `SUM_001`–`SUM_007` | “命运的齿轮”、“总而言之”、“由此可见”、“某种意义上”、“仿佛在诉说着”等 | `CRITICAL`（强制打回重写） |
| 身体反应套路 | `TIC_001`–`TIC_010` | “不禁一愣”、“心中一紧”、“眸光微闪”、“瞳孔微缩”、“嘴角勾起一抹”、副词“不禁” | `CRITICAL`（强制打回重写） |
| 结构化对称 | `SYM_001`–`SYM_004` | “不是A，而是B”、“与其说是A，不如说是B”、“是…，是…，是…”三连排比 | `CRITICAL`（强制打回重写） |
| 限知视角越界 | `POV_001`–`POV_005` | 叙述段第一人称“我”（引号内台词自动豁免）、“殊不知”、非视点人物心理动词 | `CRITICAL`（强制打回重写） |
| 伏笔与篇幅 | `LEN_*` / `FS_*` | 超出章纲字数上下限、本章应埋设或到期必收伏笔缺失物理证据词 | `CRITICAL`（强制打回重写） |
